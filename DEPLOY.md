# ConvertX Ops Website - Deployment Instructions

## 🚀 Quick Deploy Options

### Option 1: GitHub Pages (Recommended - Free Forever)
1. Go to https://github.com/new
2. Create repository: `convertxops` (make it PUBLIC)
3. Clone and push:
   ```bash
   git clone https://github.com/YOUR_USERNAME/convertxops.git
   cd convertxops
   # Copy index.html and other files here
   git add .
   git commit -m "ConvertX Ops website"
   git push
   ```
4. Enable Pages: Settings → Pages → Source: main branch → Save
5. Your site will be live at: `https://YOUR_USERNAME.github.io/convertxops/`

### Option 2: Netlify Drop (Easiest - 30 seconds)
1. Go to https://app.netlify.com/drop
2. Drag the `website` folder onto the page
3. Get instant live URL
4. (Optional) Create free account to make it permanent

### Option 3: Tiiny.host (Simple)
1. Go to https://tiiny.host
2. Upload your `index.html` file
3. Get a temporary link (free for 7 days)
4. Or create account for permanent hosting

### Option 4: Surge.sh (CLI - Fast)
```bash
npm install -g surge
cd C:/Users/inaya/convertx-os/website
surge
# Enter email and password when prompted
```
